# MP4 to MP3 Converter (TUI版)

🎵 MP4ファイルをMP3に変換する美しいインタラクティブなターミナルアプリケーション。会議録音などの音声用途に最適化されています。

## ✨ 特徴

- **インタラクティブなファイルブラウザ**: 直感的なTUIでディレクトリを移動
- **一括変換**: 複数のMP4ファイルを同時に変換
- **並列処理**: 最大3つの変換を並行実行で高速化
- **音声最適化**: 会議録音に最適な軽量設定
- **リアルタイム進捗**: ライブ進捗表示

## 🎯 最適化設定

会議録音や音声コンテンツに特化した設定：

- **ビットレート**: 64kbps（軽量）
- **サンプリングレート**: 22.05kHz
- **チャンネル**: モノラル
- **フォーマット**: MP3

## 📦 インストール

### 必要なもの

1. **Go 1.19+** - [Goをダウンロード](https://golang.org/dl/)
2. **FFmpeg** - 音声変換に必要

#### FFmpegのインストール

**macOS (Homebrew):**
```bash
brew install ffmpeg
```

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**Windows (Chocolatey):**
```bash
choco install ffmpeg
```

### ビルド

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd mp4Tomp3Converter/tui
```

2. 依存関係をインストール:
```bash
go mod tidy
```

3. アプリケーションをビルド:
```bash
go build -o mp4converter
```

## 🚀 使い方

### インタラクティブモード（推奨）

TUIファイルブラウザを起動:
```bash
./mp4converter
```

### ダイレクトモード

特定のディレクトリのファイルを変換:
```bash
./mp4converter /path/to/mp4/files
```

## 🎮 操作方法

### ファイルブラウザ

| キー | 動作 |
|-----|------|
| `↑/↓` | ファイルリストを上下に移動 |
| `Enter` / `→` / `l` | 選択したディレクトリに入る |
| `←` / `h` | 親ディレクトリに移動 |
| `Space` | 現在のディレクトリを変換対象として選択 |
| `~` | ホームディレクトリにジャンプ |
| `/` | ルートディレクトリにジャンプ |
| `.` | 初期ディレクトリに戻る |
| `q` / `Ctrl+C` | アプリケーションを終了 |

### 確認画面

| キー | 動作 |
|-----|------|
| `y` / `Y` / `Enter` | 変換開始 |
| `n` / `N` / `Esc` | ファイルブラウザに戻る |

### 変換中

| キー | 動作 |
|-----|------|
| `q` / `Ctrl+C` | アプリケーションを終了 |

### 完了画面

| キー | 動作 |
|-----|------|
| `r` | 再開（ファイルブラウザに戻る） |
| `q` / `Enter` / `Esc` | アプリケーションを終了 |

## 📁 出力構造

選択したディレクトリに `output` フォルダが作成されます：

```
選択したディレクトリ/
├── video1.mp4
├── video2.mp4
└── output/
    ├── video1.mp3
    └── video2.mp3
```

## 🐛 トラブルシューティング

**FFmpegが見つからない:**
```
Error: ffmpeg not found
```
**解決方法**: 上記の手順でFFmpegをインストールしてください。

**MP4ファイルが見つからない:**
```
Error: no MP4 files found
```
**解決方法**: ディレクトリに `.mp4` ファイルがあることを確認してください。

**パフォーマンスが遅い:**
- 大量のファイルがあるディレクトリを避ける
- ダイレクトモードを使用: `./mp4converter /path/to/files`

## 🔧 カスタマイズ

### 変換設定の変更

`mp4_converter.go` の `convertMP4ToMP3` 関数を編集：

```go
cmd := exec.Command("ffmpeg",
    "-i", inputPath,
    "-vn",           // 動画無効
    "-acodec", "mp3", // MP3コーデック
    "-b:a", "128k",   // ビットレート変更（高品質なら128k）
    "-ar", "44100",   // サンプリングレート変更（CD品質なら44.1kHz）
    "-ac", "2",       // ステレオに変更（2チャンネル）
    "-y",            // 出力ファイル上書き
    outputPath,
)
```
